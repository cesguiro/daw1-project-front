# Entre páginas

Maqueta de una librería para el proyecto de front de 1DAW. Por ahora utiliza únicamente HTML y CSS, con datos ficticios.

Abre `index.html` en el navegador para recorrer el catálogo y las pantallas de detalle, acceso, registro, carrito, compra y pedidos. Los enlaces entre páginas funcionan; las acciones y formularios están deshabilitados. Las portadas se cargan desde un servidor externo.

El [contrato inicial de la API](docs/contrato-api.md) recoge los datos y operaciones previstos para conectar el front con una API simulada o con el back real. Todavía no hay TypeScript ni una API implementada.

## Fases del proyecto

Cada fase completada se identificará con un tag de Git para poder consultar el proyecto en ese punto.
